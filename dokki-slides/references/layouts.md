# Dokki layout system

## Grid and safe zones

The logical canvas is 1920×1080. Use 120 px outer margins, a 12-column grid, 24 px gutters, and align important x positions to:

`120, 262, 404, 546, 688, 830, 972, 1114, 1256, 1398, 1540, 1682, 1800`

The automatic brand rail occupies y=48–90. Start narrative content at y=150 or lower. Keep audience content above y=920 so the web toolbar and presentation chrome never compete with it.

## Choose a named silhouette

| Layout | Best for | Composition |
| --- | --- | --- |
| `cover-signal` | Promise and framing | Large display claim plus one signal block or rule |
| `statement` | Memorable thesis | One oversized sentence and a small proof line |
| `section` | Narrative turn | Section number, short phrase, broad quiet field |
| `split` | Tension plus explanation | 5/7 or 7/5 vertical split; one dominant side |
| `data-hero` | One number that matters | 40% KPI, 60% context or compact chart |
| `comparison` | Before/after or two choices | Two aligned fields separated by one vertical rule |
| `timeline` | Time and milestones | Horizontal baseline with 3–5 uneven milestones |
| `process` | Ordered actions | Connected verbs; highlight only the current shift |
| `architecture` | System relationships | 2–4 layers or nodes with directional links |
| `chart-ledger` | Quantitative evidence | Claim/title above a large chart and source line |
| `image-hero` | Visual evidence | 7/5 image-text split or full-bleed image with quiet zone |
| `matrix` | Two-axis decision | Large 2×2 field with sparse labels, not cards |
| `closing-split` | Decision and next action | Dark or signal field paired with a concrete action |

## Rhythm rules

- For 5+ slides, use named layouts on at least 60% of the slide count as distinct silhouettes.
- Never repeat the same layout three times in a row.
- Follow a dense evidence slide with a breathing statement, section, or image slide.
- A 7–8 slide deck should normally use at least six layouts.
- Alternate scale and mass, not brand identity: the palette, rail, typography, and grid remain fixed.

## Selection router

- A single memorable assertion → `statement`.
- One decisive metric → `data-hero`; several values over categories → `chart-ledger`.
- Two options sharing dimensions → `comparison`; independent ideas → `split`.
- Ordered verbs → `process`; dated change → `timeline`.
- Components and flow → `architecture`; axes and quadrants → `matrix`.
- A photograph or diagram is the evidence → `image-hero`.

Do not force content into a visually fashionable layout. Change the silhouette when the information relationship changes.
